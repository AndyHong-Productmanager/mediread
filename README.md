# 메디리드 · mediread

메디리드 제품 소개 랜딩페이지입니다. HTML, CSS, JavaScript로 구성된 정적 사이트이며 별도의 빌드 과정 없이 실행할 수 있습니다.

## 실행

```sh
python3 -m http.server 8080
```

브라우저에서 http://localhost:8080 을 엽니다.

## 구성

- `index.html`: 랜딩페이지 콘텐츠
- `styles.css`: 스타일 및 반응형 레이아웃
- `main.js`: 모바일 메뉴, 카테고리 캐러셀, 제품 영상 재생 연동
- `assets/`: 제품 스크린샷, 로고, 46초 제품 데모 영상

## 배포

정적 호스팅 서비스의 게시 디렉터리를 저장소 루트(`.`)로 지정합니다. 빌드 명령은 필요하지 않습니다.

## 콘텐츠 설정

요금, 사업자 정보, 문의 및 약관 링크는 `index.html`에서 관리합니다. 공개 운영 전 현재 임시 내용을 실제 서비스 정보로 교체해야 합니다.

영상 파일은 `assets/mediread-product-demo.mp4`이며 `#features` 섹션에 연결되어 있습니다. 영상 교체 시 `data-time` 구간 표시도 영상 타임라인에 맞춰 변경합니다.
